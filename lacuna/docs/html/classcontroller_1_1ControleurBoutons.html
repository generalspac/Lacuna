Detailed Description

------------------— CONTRÔLEUR BOUTONS -----------------------— //

Centralise les actions des boutons de l'interface graphique.

Cette classe permet de :

  • annuler un coup
  • refaire un coup
  • recommencer une partie
  • abandonner une partie
  • afficher l'aide visuelle
  • gérer le feedforward
