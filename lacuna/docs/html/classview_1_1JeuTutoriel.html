Detailed Description

Version tutorielle du jeu avec progression guidée.

Cette classe hérite de JeuGraphique et impose un déroulement pas-à-pas pour apprendre les mécaniques du jeu :

  • sélection de fleurs
  • validation de paires
  • placement de pion
  • gestion des erreurs
