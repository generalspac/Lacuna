Detailed Description

-------------------— PARAMÈTRES PARTIE ---------------------— //

Contient tous les paramètres nécessaires au lancement d'une partie.

Cette classe permet de centraliser :

  • le mode de jeu
  • les noms des joueurs
  • les niveaux des IA
  • le joueur qui commence
