◆ jouerCoup()

void model.Jeu.jouerCoup ( Joueur joueur,
Pion pion,
Coordonnees pos,
Fleur f1,
Fleur f2 )

A REVOIR : cette fonction est appelée après ajustement de la position, elle vérifie si la position finale est valide pour le pion. Ajuste la position d'un pion s'il chevauche une fleur ou un autre pion. Tente de le décaler légèrement pour qu'il soit côte à côte. Applique un coup complet de phase 1.

Le coup place le pion, collecte les deux fleurs, l'enregistre dans l'historique et passe au joueur suivant.

Parameters
joueurjoueur qui joue.
pionpion libre du joueur.
posposition validée pour le pion.
f1première fleur collectée.
f2seconde fleur collectée.
